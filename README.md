# Shifra Virtual Assistant

A responsive browser-based virtual assistant built with HTML, CSS, and vanilla JavaScript.

## Run

Open `index.html` in a modern browser. Chrome or Edge provides the best speech-recognition support.

## Features

- Text and voice input
- Spoken responses with mute control
- Safe basic calculations
- Date, time, shortcuts, and web-search fallback
- Persistent conversation history
- Light and dark themes
- Responsive and accessible interface

Shifra uses built-in browser logic and is not connected to a generative AI service.
